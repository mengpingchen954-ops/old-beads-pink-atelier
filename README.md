# Old Beads Pink Atelier

粉色欧美卡通手绘版《旧珠新约》：顺序串珠闯关、首次通关建造星、修复小店 / 工坊 / 玫瑰庭院，以及自由手串设计。

本目录是独立新版，使用 `old-beads-pink-v1` 存档键；旧版仓库和旧网址保持不变，方便对比。

## 本地运行

```bash
npm ci
npm test
npm run dev
```

## 可玩的内容

- 12 关串珠委托：从料杆左端取珠，利用木盘暂存，按手串顺序交付；支持点击、鼠标和触屏拖拽、撤销、提示、重开与断点续玩。
- 首次通关获得金币和 1 颗建造星；回小店点修复标记并确认才会花星，重复通关不重复发奖。
- 小店、工坊、庭院共有 12 项独立修复；完成前一区域的 4 项修复后开放下一片区域，也能回访已开放区域。
- 委托地图、来信作品册、自由搭配、珠宝盒、绒盘购买和橱窗展示。
- 背景音乐使用用户提供的 6 首 MP3 顺序循环；首次点击后播放，跨场景连续，切到后台暂停。声音设置支持整体音量、独立音乐音量与音乐开关，设置随存档保存。

工作台布局、顾客卡片、珠子材质、结算、地图和搭配界面均已重新绘制。场景和人物采用用户已批准的 Seedream 5.0 Pro 设计中的独立素材裁切，配合程序绘制的修复层、按钮和资源数字；本次修订没有新增付费生图。所有交互均由实际游戏逻辑驱动。

## 验证与发布

`npm test` 验证规则、存档、关卡、奖励及建设；浏览器回归脚本在 `tests/*playthrough.mjs` 与 `tests/feel.mjs`，默认连接本地 5220 端口，支持用 `GAME_URL` 指定部署地址。

`npm run build` 生成静态站点，GitHub Actions 自动部署到 [新版游戏](https://mengpingchen954-ops.github.io/old-beads-pink-atelier/)。[原版](https://mengpingchen954-ops.github.io/old-beads-new-promises/) 保持独立。
